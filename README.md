## Projetos que representam meu trabalho

### [Deusa Insights](https://github.com/MatheusBetelli/Deusa-Insights)

Plataforma interna de inteligência comercial para a Deusa Alimentos. A solução cruzou aproximadamente **4.688 empresas em 26 cidades** e organizou cerca de **1.400 oportunidades de prospecção**, combinando dados de estabelecimentos, localização, score e informações públicas de contato.

`TypeScript` `React` `NestJS` `PostgreSQL` `Prisma` `Google Maps APIs` `Google Cloud`

### [EggVision](https://github.com/BrunoMorgadoGit/egg_vision)

Projeto de visão computacional para classificação de ovos. Estruturei preparação, treinamento, validação e inferência de um modelo YOLOv8 com **130 imagens**, alcançando aproximadamente **97% nas métricas de avaliação**. **2º lugar no Simpósio de Ciência de Dados — 2026.**

`Python` `YOLOv8` `OpenCV`

### [Aplicação Full Stack de Gestão](https://github.com/BrunoMorgadoGit/Teste_estagio_Momesso)

Aplicação para gerenciamento de empresas, usuários e máquinas, com API em NestJS, frontend Angular, PostgreSQL, autenticação JWT, CRUD e regras de acesso por perfil.

`NestJS` `Angular` `PostgreSQL` `TypeORM` `JWT`
